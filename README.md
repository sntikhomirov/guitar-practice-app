# Гитарные упражнения

Небольшое desktop-приложение на Python/Tkinter для занятий на гитаре.

Текущая версия: `0.1.0`.

## Возможности

- счётчик удачных и неудачных попыток;
- подсчёт текущих серий удач/ошибок;
- подсказка, когда прибавлять или убавлять сложность;
- журнал занятий;
- добавление упражнений с названием и описанием;
- запись темпа, длительности и даты занятия;
- просмотр журнала в виде таблицы с максимальными темпами;
- сортировка упражнений в таблице по максимальному темпу, приведённому к четвертям.

## Запуск

```bash
python3 counter.py
```

Альтернативный запуск:

```bash
python3 -m guitar_practice_app
```

## Тесты

```bash
python3 -m unittest
```

## Структура проекта

```text
counter.py                 # точка входа
guitar_practice_app/       # код приложения
  gui.py                   # Tkinter-интерфейс
  models.py                # модели данных
  services.py              # бизнес-логика
  settings.py              # настройки приложения
  storage.py               # чтение/запись JSON
tests/                     # тесты
CHANGELOG.md               # история версий
```

## Данные

Журнал занятий хранится локально в файле `journal_data.json` рядом с приложением.
Этот файл добавлен в `.gitignore`, чтобы личные записи случайно не попали в репозиторий.

Пример структуры данных есть в `journal_data.example.json`.

## Темпы и длительности

Для сравнения темпов разные длительности приводятся к четвертям:

| Длительность | Отображение | Коэффициент |
|---|---:|---:|
| четверти | `4` | `1` |
| восьмые | `8` | `2` |
| восьмые триоли | `8т` | `3` |
| шестнадцатые | `16` | `4` |
| шестнадцатые триоли | `16т` | `6` |

Приведённый темп считается как `BPM × коэффициент`.
Например, `55 / 8т` отображается в строке максимумов как `55 / 8т (=165)`.
